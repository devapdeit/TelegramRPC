# Telegram RPC | By Apdeit

Графическое приложение в морско-белом стиле для передачи музыки из Telegram Desktop в Discord Rich Presence.

## Что получает друг

После сборки отправляйте только файл:

```text
dist\TelegramRPC_By_Apdeit.exe
```

В него уже включены Python и все библиотеки. Другу не нужны `setup.bat`, Python, pip или исходники.

## Перед первой сборкой

1. Откройте `build_config.json`.
2. Вставьте свой числовой Discord Application ID:

```json
{
  "discord_client_id": "123456789012345678",
  "large_image": "telegram_music",
  "large_text": "Музыка из Telegram"
}
```

3. В Discord Developer Portal загрузите Rich Presence Asset с ключом `telegram_music`.
4. Запустите `build.bat`.
5. Готовый EXE появится в папке `dist`.

## Возможности

- современный морско-белый интерфейс;
- запуск и остановка RPC одной кнопкой;
- проверка запущенного Discord;
- предложение автоматически открыть Discord;
- отображение названия, исполнителя, паузы и таймера;
- автоматическое переподключение после перезапуска Discord;
- системный трей;
- автозапуск с Windows;
- автоматический запуск RPC;
- журнал ошибок и подключений;
- хранение пользовательских настроек в `%APPDATA%\TelegramRPC_By_Apdeit`.

## Важное ограничение

Если Telegram Desktop не передаёт реальную позицию трека в Windows Media Control, таймер начинается с момента обнаружения песни. Пауза учитывается.

## Антивирус Windows

Не подписанные приложения, собранные через PyInstaller, иногда получают предупреждение SmartScreen или ложное срабатывание антивируса. Для публичного распространения рекомендуется подписать EXE сертификатом code signing.
